## 🗂 Структура проекта

```
barbershop/
├── mainmenu.html        # Главная страница — интерьер, описание, философия
├── masters.html         # Мастера — профили барберов (Рахлин, БудГусам)
├── gallery.html         # Галерея — отзывы клиентов с фото и оценками
├── services.html        # Услуги — прайс-лист, описание услуг, пакеты
├── registration.html    # Запись — онлайн-форма записи к мастеру
├── style.css            # Единый файл стилей для всех страниц
└── *.png / *.jpg        # Изображения: интерьер, работы мастеров, аватары
```

- Блок с описанием преимуществ и философии

### 📝 [registration.html](registration.html) — Онлайн-запись
Форма записи с полями:
- Имя клиента
- Телефон
- Выбор услуги (выпадающий список)
- Выбор мастера (Будгус / Рахлин)
- Дата и время (10:00 – 20:00, шаг 2 часа)
- Кнопка «Записаться сейчас»

## 🎨 Дизайн и стилизация

| Параметр | Значение |
|----------|----------|
| **Цветовая схема** | Тёмная тема (фон `#161616`, текст `#c1c1c1`) |
| **Акцентный цвет** | Красный `#d32f2f` (кнопки, разделители, ссылки) |
| **Шрифты** | Times New Roman (заголовки), Arial (текст) |
| **Навигация** | Sticky header + навигационная панель |
| **Карточки** | Скруглённые углы (`border-radius: 15–50px`), тени |
| **Поля формы** | Тёмные инпуты с округлёнными границами |
